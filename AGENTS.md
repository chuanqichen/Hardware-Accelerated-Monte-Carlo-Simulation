# Project notes

ECE 382M-7 VLSI I, Fall 2026. Lane-parallel Monte Carlo European call pricer:
`S_T = exp(A + B*Z)`, xoshiro RNG -> inverse-normal LUT -> fixed-point datapath ->
payoff accumulator; compare 1/2/4 lanes. Scope is `docs/Project_Proposal.md`.

## Layout
- `model/` Python reference (numpy only; no scipy - use `statistics.NormalDist`)
- `rtl/` SystemVerilog; `rtl/generated/` is script output, never hand-edit
- `tb/` testbenches; `tb/vectors/` generated by `model/gen_*_vectors.py`
- `docs/` proposal + per-block work plans; `docs/course/` handouts (gitignored);
  `docs/references/` literature notes and `.bib`
- `scripts/`, `constraints/`, `reports/` (raw tool output), `results/` (parsed CSV/plots)
- Generated PDFs (`docs/*.pdf`) are gitignored; build with `make docs`

## Git
- Commit messages: plain summary + body only. Do NOT add "Generated with Devin"
  or `Co-Authored-By: Devin ...` trailers.

## Conventions
- Modules/files `snake_case`, parameters `UPPER_SNAKE`, active-low `_n`
- Fixed point: one policy everywhere - round-half-to-even then saturate
  (`model/fxp.py`); no silent truncation in RTL
- ROMs are emitted as `case` statements for Design Compiler (no `$readmemh`)

## Commands
```bash
make test            # model unit tests
make sweep           # LUT sweep: exact stats + price bias
make gen ADDR_BITS=10  # regenerate ROM RTL + TB vectors
make sim             # VCS tb_gauss_lut (lab machines; no simulator on the laptop)
make lint            # verilator --lint-only, if installed
make docs            # pandoc + xelatex -> docs/*.pdf
```
No simulator is installed on the dev laptop (macOS, Python 3.9.6, numpy 2.0.2).
